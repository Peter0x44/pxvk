# Classic GPU PhysX compatibility

An experimental project investigating how to run classic 32-bit NVIDIA GPU PhysX 2.8.x-era CUDA workloads through an eventual Vulkan compute backend.

Mirror's Edge (2009) is the initial research and compatibility target. Implementation has not started; the project is currently gathering evidence from existing work, native NVIDIA traces, and the game's finite CUDA/PTX workload.

See [`docs/charter.md`](docs/charter.md) for scope and strategy.
